# fixed-cost-manager（サブスク・固定費管理）

サブスクリプションや固定費の契約を登録し、月間・年間の費用を集計する1画面の Web アプリです。
Claude Artifacts の「Install as app」（Claude デスクトップアプリからのデスクトップアプリ化）を技術検証するために作りました。

- 現在のバージョン：**v0.2**（画面の見出しに表示）
- ライセンス：**未決定**（LICENSE ファイルはまだありません）

---

## 開発背景

- 目的は、Claude Artifacts の「Install as app」を使ってデスクトップアプリ化を技術検証することです。題材として、最小構成のサブスク・固定費管理アプリを選びました。
- 最初は Claude Design（キャンバス）で作りましたが、`desktop` 機能を宣言できなかったため、通常の HTML Artifact として作り直しました。
- Artifact の自動更新を検証するため、画面の見出しを「サブスク・固定費管理 v0.2」に変更しました。
- ソースコードの正本は GitHub のこのリポジトリです。Artifact は公開先として扱います（後述の「開発・公開フロー」）。

### HTML・CSS・JavaScript を3ファイルに分離した経緯

- 当初は `index.html` 1ファイルに HTML・CSS・JavaScript をまとめていました。これは Claude で手作りのページを作るときの既定の進め方に従ったもので、プラットフォームの必須要件ではありません。
- Claude Artifacts は、ファイル群から公開したページが自分のファイルを相対パスで読み込むことを認めています。そのため、分離しても仕様上の問題はありません。
- 関心の分離（Separation of Concerns）による保守性と読みやすさを重視し、`index.html`・`style.css`・`app.js` の3ファイルに分離しました。
- 分離は中身を変えない切り出しのみで行いました。分割した3ファイルを結合すると、分離前の `index.html` と完全に一致することを確認済みです。

## 現在の機能（実装済み）

- **契約の登録：** 契約名・月額料金（円）・次回更新日を登録できます。
  - 入力チェックがあります。契約名は必須で最大60文字です。月額は0以上の数値で、整数に丸めます。更新日は必須です。
- **一覧：** 登録した契約を次回更新日の順に表示します。
- **編集・削除：** 一覧の各行から編集・削除できます。編集中の行は色付きで表示されます。
- **集計：** 月間費用（月額の合計）と年間費用（月額 × 12）を自動で計算します。
- **グラフ：** 契約別の月額費用を横棒グラフで表示します。金額の大きい順に並び、合計に対する割合も表示します。
- **データの永続化：** 実行環境に応じて保存先が変わります（後述）。
- **保存先の表示：** 画面下部に、データがどこに保存されているかを表示します。
- **インストールボタン：** Claude デスクトップアプリでインストールできる状態のときだけ、「アプリとしてインストール」ボタンを表示します。
- **アプリアイコン：** インストール済みアプリのウィンドウで動いているとき、独自のアイコン（青地に棒グラフ）を設定します。
- **画面：**
  - 日本語 UI、金額は日本円（`¥` と3桁区切り）で表示します。
  - 1画面の構成です。画面幅が狭いと、フォームと一覧が折り返して縦に並びます。幅600px以下では、グラフの行も縦に並ぶレイアウトに切り替わります。
  - ライト・ダークのテーマに対応しています。

## 使用技術

- HTML / CSS / JavaScript（ライブラリなし、ビルド不要）

## 実行方法

### Claude 上で実行する

1. **開く：** 下記の Artifact の URL を開きます。Claude へのサインインが必要です。
2. **インストールする（任意）：** Claude デスクトップアプリで開き、次のどちらかの方法でインストールします。
   - 画面下部の「アプリとしてインストール」ボタンを押す（表示される場合のみ）
   - Artifact のメニューの「Install as app」を選ぶ

### Claude の外で実行する（ローカル）

- **直接開く：** `index.html` をブラウザで直接開きます。
- **ローカルサーバーで開く（開発時の推奨）：** VS Code / Cursor の Live Server などのローカルサーバーで開きます。

Claude の外では、データベースへの保存とインストール関連の機能は使えません。その場合、データはブラウザの localStorage に保存されます。

## Claude 固有の機能への依存関係

| 箇所 | ファイル | 内容 | Claude の外での挙動 |
|---|---|---|---|
| 権限宣言タグ `claude-artifacts-manifest` | `index.html` | インストール時に要求する権限の宣言です。現在は `{"permissions": []}` で、追加の権限は要求しません。 | 無視されます。 |
| `claude.use('db')` / `claude.use('user')` | `app.js` | ユーザーIDを取得し、本人専用領域に読み書きします（`docRef.get()` / `docRef.set()`）。 | `claude` が存在しないため失敗します。エラーは捕捉され、localStorage への保存に切り替わります。 |
| `claude.use('desktop')` | `app.js` | インストール状態の確認、インストールの要求、アプリアイコンの設定を行います。 | 失敗しますが、エラーは捕捉されます。インストールボタンは表示されません。 |

### ファイルに含まれないもの（Artifact 側で管理）

- **機能の宣言：** `db`・`user`・`desktop` の宣言と、次のデータベースのアクセスルールです。

  ```json
  {
    "desktop": {},
    "user": {},
    "db": {
      "rules": [
        { "path": "", "read": "owner", "write": "owner" },
        { "path": "data/users/{self}", "read": "interact", "write": "interact" }
      ]
    }
  }
  ```

- **登録データ：** Artifact のデータベースに保存されています。

## 実行環境ごとのデータ保存先

| 実行環境 | 保存先 |
|---|---|
| Claude 上（ブラウザ・インストール済みアプリ）、サインイン済みでデータベースが使える場合 | Artifact のデータベースのドキュメント `data/users/<ユーザーID>/subscriptions` に保存します。本人のみ読み書きでき、他の人からは見えません。同じ内容を、その端末の localStorage（キー `subs-manager-v1`）にも保存します。 |
| Claude 上で、データベースが使えない場合（サインアウト中など） | その端末の localStorage（キー `subs-manager-v1`）のみに保存します。 |
| Claude の外（ローカル実行） | そのブラウザの localStorage（キー `subs-manager-v1`）のみに保存します。Artifact のデータとは共有されません。 |

### 読み込み時の動作（`app.js`）

1. まず localStorage のデータで画面を描画します。
2. データベースが使える場合は、次のように処理します。
   - データベースにデータがある：その内容で画面を置き換え、localStorage にも書き込みます。
   - データベースが空で、localStorage にデータがある：localStorage のデータをデータベースに保存します。

### データ形式

ドキュメントは `{ items: [...], updatedAt: <ISO 8601 文字列> }` の形です。`items` の各要素は次の形です。

```js
{ id: string, name: string, fee: number, date: "YYYY-MM-DD" }
```

## GitHub を正本とした開発・公開フロー

1. **編集：** このリポジトリを clone し、手元で編集します（例：`D:\dev\fixed-cost-manager`）。
2. **ローカル確認：** Live Server などで確認します。データは localStorage に保存され、Artifact のデータには影響しません。
3. **push：** 変更をコミットし、GitHub に push します。
4. **Artifact に反映：** Claude に「GitHub の最新を Artifact に反映して」と依頼します。`index.html`・`style.css`・`app.js` を**1回の操作でまとめて**公開し、1つの新しいバージョンにします。`README.md` は公開しません。
5. **タグ付け（任意）：** 公開したコミットに `v0.3` などのタグを付け、公開中のバージョンと対応させます。

### 注意

- Artifact だけを直接変更しないでください。変更した場合は、同じ変更を必ずこのリポジトリにもコミットします。
- GitHub と Artifact は自動では同期しません。
- 機能の宣言とアクセスルールは Artifact 側で管理しています。変更したときは、このファイルの「Claude 固有の機能への依存関係」も更新します。

### 制約

- **年間費用：** 月額 × 12 の固定計算です。年払いなど月額以外の契約には対応していません。
- **データベースへの保存：** Claude へのサインインが必要です。
- **ローカル実行時のデータ：** Claude の外で実行した場合のデータは、そのブラウザ内にだけ保存されます。Artifact のデータとは別です。
- **データの移行：** localStorage と Artifact のデータベースの間で、データを書き出したり取り込んだりする機能はありません。
- **アプリ名：** インストールしたアプリの名前は `<title>`（「サブスク・固定費管理」）から決まります。v0.2 の表記は画面の見出しだけに付けています。
